## 三、为什么香港反而更贵？

### 3.1 价格差异原因

1. **定价策略不同**
   - Apple各地区独立定价
   - 香港税率虽低，但定价不低
   - 中国大陆市场竞争激烈，价格更优

2. **增值税差异**
   - 中国大陆：含13%增值税
   - 香港：无增值税（0%）
   - 理论上香港应该便宜，但Apple定价策略导致反而更贵

3. **历史原因**
   - 过去港币较弱时香港更便宜
   - 现在港币与美元挂钩，价格优势消失

### 3.2 实际对比

```
中国大陆官方价：¥18,999
香港官方价：    ¥20,924 (HK$22,499)
差异：          贵¥1,925 (10.1%)

结论：去香港买不划算！
```
